# LingoFlow Mobile

Первый Expo/React Native vertical slice для iOS и Android: Supabase email/password auth, защищённое хранение сессии и owner-scoped `GET /api/v1/me/bootstrap/` с экраном «Сегодня».

```bash
cp .env.example .env
npm ci
npm run verify
npm start
```

В `.env` нужны URL Django API, URL Supabase и только публичный publishable key. `service_role`, database password и другие серверные секреты в Expo добавлять нельзя: `EXPO_PUBLIC_*` встраивается в приложение.

Сессия на iOS/Android хранится через Expo SecureStore. Мобильный поток открывает
уроки из Today, проверяет choice/sentence-builder ответы на сервере и сохраняет
результат идемпотентным событием. Персональные данные offline пока не кэшируются.
Повтор сохранения использует тот же полный пакет результата, включая время;
неподтверждённый итог можно отправить повторно с отдельного экрана. Пакет
живёт только до ухода с экрана: фоновой offline-очереди пока нет.
Балл и позиция карточки меняются после подтверждения сохранения, повторные
нажатия блокируются. Смена аккаунта/выход уничтожают состояние учебных экранов;
обновление токена того же ученика сохраняет открытый маршрут.
Позиция и текущий счёт незавершённого урока сохраняются owner-scoped на сервере,
поэтому урок можно продолжить после перезапуска или на другом устройстве.
Beta-пользователь может отправить категоризированную обратную связь через
существующий owner-scoped API; приложение не прикладывает токены и device data.
Задание словаря в Today открывает только due-карточки личной SM‑2 очереди;
ответ нужно показать до оценки, а расписание обновляется owner-scoped на сервере.
Раздел «Читать» показывает учебные тексты A1–C2, синхронизирует закладки,
добавляет только проверенные glossary-леммы в словарь и открывает comprehension.
Аудирование A1–B2 использует системный `pl-PL` TTS с тремя скоростями,
фрагментами, постоянным транскриптом и stateless проверкой ответов на сервере.
Профиль синхронизирует имя, уровень A1–C2 и дневную цель. Там же находится
выход из аккаунта и opt-in будущих напоминаний; интерфейс явно сообщает, что
push-доставка ещё не активирована.
Карточка «Темы практики» отдельно сохраняет исключение удалённой/гибридной
работы через bearer-only `GET/PATCH /api/v1/me/practice-preferences/`.
Выбор общий с web-профилем. «Практика» читает оттуда рекомендацию навыка B2;
полный каталог остаётся доступен. При ошибке загрузки настройка не редактируется
до повтора, при ошибке записи успех не показывается. Для A1/A2/B1/C1/C2 новая
рекомендация пока не выдаётся. Подробности и границы проверки:
[контракт синхронизации](../docs/practice-preferences-sync-2026-10-15.md).
Достижения вычисляются из синхронизированного прогресса, а история показывает
owner-scoped результаты за 7, 30, 90 дней или всё время с пагинацией.
Диагностика сопоставляет самооценку с восемью проверяемыми заданиями без
сохранения ответов. Раздел письма хранит черновик только в памяти и по явной
команде проверяет объём, абзацы и маркеры, но не качество или уровень CEFR.
Экран достижений показывает семь детерминированных целей по синхронизированным
урокам, серии занятий и словарю без отдельного изменяемого состояния наград.
Экран диагностики объединяет самооценку четырёх навыков и восемь проверяемых
заданий через stateless API. Ответы и результат не сохраняются, а рекомендация
является ориентиром для старта, не экзаменом, сертификатом или подтверждением CEFR.
Тренажёр взаимодействия и медиации включает выбор реплики, сборку порядка и
локальные свободные ответы с ручным чек-листом; такие черновики не отправляются.
Все дополнительные навыки и статистика собраны в разделе «Практика», поэтому
«Сегодня» снова сфокусирован на цели, продолжении урока и плане дня.

Порядок подписанной сборки и её приёмки — в
[инструкции мобильной beta](../docs/mobile-beta.md).
`npm run verify` проверяет код, а `npm run build:check -- --platform ios --check-session`
отдельно проверяет условия попытки сборки и показывает недостающую настройку
без значений ключей. EAS CLI закреплён на 24.14.0 (`npm run eas -- …`).
Успешный preflight не подтверждает подпись или установку: нужны настоящие
Expo-проект/сессия, а для физического iPhone — Apple Developer и provisioning.

`npm run test:learning` проверяет обработчики настоящих TSX-модулей с
управляемыми hooks и сетевыми фикстурами. Это regression логики, не нативный
renderer; установка, системный lifecycle и доступность проверяются на build.
