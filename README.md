# LingoFlow

Mobile-first приложение для ежедневного изучения польского языка. Основная и
единственная production-версия работает на Python/Django, использует Supabase
для PostgreSQL и авторизации и разворачивается в Vercel.

Production: [lingoflow-learn.vercel.app](https://lingoflow-learn.vercel.app)

## Что уже работает

- регистрация, вход, безопасные пользовательские сессии через Supabase Auth;
- новые пароли проверяются приложением: минимум 10 символов, разные регистры,
  цифра и блокировка распространённых комбинаций;
- ежедневный план, серия дней и сохранение завершённых уроков;
- уроки слов, грамматики, повторения и мини-тест;
- библиотека адаптированных текстов с интерактивным glossary и отдельной
  проверкой понимания после каждого чтения;
- личный словарь и повторение сохранённых слов по SM-2;
- структура контента `Course → Topic → Lesson` и управление через Django Admin;
- каталог курсов с отдельными разделами A1, A2, B1, B2, C1 и C2;
- курс и библиотека чтения по умолчанию открывают текущий уровень профиля;
- завершённая программа A1 из 12 вертикальных тем, включая итоговую диагностику;
- завершённая программа A2 из 12 вертикальных тем с чтением и проверкой понимания;
- завершённая программа B1 из 12 вертикальных тем, включая итоговый проект;
- завершённые программы B2 из 12 тем и C1 из 10 тем;
- полная целевая программа C2 из десяти вертикальных тем;
- редактируемый профиль с прогрессом, страница источников и сохраняемая
  светлая/тёмная тема;
- достижения за уроки, серии занятий, словарь и активные дни;
- письменная практика B1/B2 с локальными черновиками и самопроверкой, включая
  семь экзаменационно полезных жанров B1 и адресные уроки для отмеченных ошибок;
- диагностика с отдельными самооценкой и короткой проверяемой пробой;
- аудирование слов и оригинального мини-диалога с транскриптом и повтором;
- сценарные тренировки взаимодействия и медиации B1/B2, включая устную
  практику B1 с таймером, самопроверкой и добровольной локальной историей до
  десяти записей без загрузки аудио на сервер;
- отдельный режим подготовки к государственному экзамену B1: обратный отсчёт,
  ежедневный 15-минутный план, пять официальных модулей и честная панель
  измеряемых результатов чтения/грамматики за 30 дней, а также недельный
  15-минутный мини-модуль с раздельной оценкой проверяемых частей и
  идемпотентной историей попыток без дублей при повторной отправке; каждую из
  пяти частей можно отдельно тренировать с полным лимитом времени;
  для коротких проверяемых наборов добавлен учебный режим на 8/7/6 минут
  с отдельным прогрессом и явным объяснением расчёта;
  отдельные проверяемые части используют расширенные оригинальные наборы из
  пяти заданий на аудирование и чтение и шести заданий на грамматику;
  таймер отдельной части продолжается после перезагрузки, а на общем экране
  локально видны незавершённые и завершённые попытки без сохранения ответов;
  агрегированные результаты аудирования, чтения и грамматики сохраняются в
  owner-scoped истории между устройствами и входят в экспорт данных;
- устанавливаемый PWA-прототип с безопасной публичной offline-оболочкой;
- публичный read-only API v1 каталога для будущих мобильных клиентов;
- системное польское озвучивание всех оригинальных текстов;
- A1-пилот аудирования на трёх проверенных public-domain записях с заданиями и
  видимой атрибуцией;
- адаптивный интерфейс для телефона и desktop;
- новости внутри раздела «Читать» из нескольких источников с тематическими фильтрами;
- основная навигация из пяти учебных направлений: Сегодня, Курс, Практика,
  Читать и Словарь;
- недельная/месячная активность, мягкая 28-дневная аналитика дневной цели и
  быстрый переход от текста к SM-2-тренировке.

## Стек

| Часть | Технологии |
| --- | --- |
| Web | Python 3.12, Django 5.2, Templates, HTMX |
| Данные и Auth | Supabase Postgres, Auth, RLS |
| Доставка | GitHub Actions, Vercel |

Отдельный Next.js-клиент удалён после успешного переноса production. Runtime и
сборка остаются Python-only; полный test suite дополнительно использует Node.js
только для изолированного regression-теста браузерной offline-очереди.

## Быстрый запуск

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
cp .env.example .env.local
python manage.py migrate
python manage.py check
python manage.py test
python manage.py runserver
```

По умолчанию используется локальная SQLite. Для Supabase Auth заполните в
локальном окружении публичные `SUPABASE_URL` и `SUPABASE_ANON_KEY`. Для работы
Django Admin с production-подобным PostgreSQL дополнительно задайте
`DATABASE_URL`; секреты нельзя коммитить в Git.

Подробная настройка окружения, базы и Vercel описана в
[`backend/README.md`](backend/README.md).

## Проверки

```bash
cd backend
.venv/bin/python manage.py test
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
```

Эти проверки выполняются GitHub Actions для pull request и `main`. Vercel
автоматически разворачивает Django-проект `lingoflow-learn` с корневой
директорией `backend`.

## Supabase

Для новой пустой базы сначала применяется `supabase/schema.sql`, затем миграции
из `supabase/migrations/` в порядке их имён. Пользовательские данные защищены
RLS; приложение обращается к ним с access token пользователя и не использует
`service_role`.

## Реализованная основа

- 68 тем A1–C2, Django web-продукт, адаптивный Today, SM-2, синхронизация
  прогресса, контролируемая offline-очередь и native-ready API.
- B1: экран подготовки, результаты пяти модулей, недельный mini-mock из трёх
  проверяемых блоков и двух блоков самопроверки, история агрегированных баллов,
  устная практика с локальной записью и экзаменационные жанры письма.
- Today: планы на 10/15/30 минут, skill-теги и недельная ротация B1;
  письмо формирует локальный план закрепления отмеченных ошибок.
- Expo/React Native: login, bootstrap, Today, lesson/answer/result,
  cross-device resume, reading→dictionary→SM-2, listening A1–B2, feedback,
  редактируемый профиль и EAS build-профили.

Уровни остаются curriculum targets, а не официальной CEFR-оценкой.
Основа подходит для закрытой beta; широкому запуску нужны проверки ниже.

### Улучшения B1 и quality sprint

- B1 resume: ответы и письменный черновик в текущей вкладке, исходная
  подписанная mini-mock попытка и таймер по фактическому времени.
- Учебный таймер 8/7/6 минут, отдельный полный лимит, удаление текста,
  статус сохранения и предупреждение при отказе хранилища.
- Один основной `<main>` на B1-страницах; объявления таймера на 10/5/1 минутах
  и при истечении времени.
- `private, no-store` для login/register, включая ошибки и перенаправления.
- «Załóż konto» на регистрации; диапазон A1–B2 и быстрые переходы аудирования.
- Явный состав mini-mock, объёмы 2/2/3 вопроса и предупреждение о низкой
  уверенности маленькой выборки.
- Приоритет B1 по среднему баллу последних 3–5 mini-mock попыток;
  до трёх попыток mini-mock не меняет приоритет плана.
- Автоматическая версия публичного PWA-кэша из commit/deployment ID;
  локально используется хэш оболочки, CSS и favicon вместо ручного `v32`.
- Production smoke отклоняет HTTP-перенаправления и не переносит bearer-токен
  на другой адрес; регрессии покрывают коды 301/302/303/307/308.
- Польские инструкции пяти B1-частей и недельного mini-mock;
  русский перевод открывается по запросу и доступен с клавиатуры.
- В настройках профиля можно исключить удалённую/гибридную работу из новых B1-вариантов
  и персональной рекомендации B2. Выбор хранится в этом браузере до 90 дней,
  привязан к аккаунту и удаляется при отключении; общий каталог не меняется.
- Учебный прогон B1: пять частей по порядку, серверные лимиты 8/45/45/35/11 минуты,
  двухминутные перерывы и подписанный отчёт по модулям без общего балла.
  Ответы и письмо восстанавливаются в текущей вкладке; после части остаются
  только агрегаты или отметка самопроверки. Прогон действует до четырёх часов
  и не добавляется в историю аккаунта. Объём ещё меньше полного экзамена.
  В устной части доступна добровольная запись с прослушиванием и удалением.
  Аудио остаётся в памяти страницы; таймер и уход выключают микрофон,
  перезагрузка или завершение части удаляют запись.
  Аудирование в этом прогоне ограничено двумя прослушиваниями с паузой
  30 секунд. Счётчик восстанавливается в текущей вкладке; не запустившийся
  голос не расходует попытку. Пока используется системный голос устройства.
  Грамматика версии 2 расширена до 20 заданий: шесть зависят от
  варианта, 14 общие. Начатые прогоны сохраняют прежние объём и лимит.
  Перезагрузка после старта части восстанавливает её состояние и таймер,
  не повторяя операцию старта.
  Чтение новых прогонов: четыре текста и 20 вопросов за 22 учебные минуты.
  К тексту варианта добавлены общие объявление, письмо и небольшой рассказ;
  вопросы сгруппированы рядом с соответствующим текстом.
  Письмо новых прогонов: два задания на 50–80 и 140–170 слов за 35 учебных
  минут, отдельные черновики со счётчиками объёма и независимым удалением.
  Оба текста восстанавливаются в текущей вкладке и удаляются после части;
  на сервер отправляется только подтверждение самопроверки.
  Говорение пятой версии: личный рассказ, описание вымышленной ситуации
  и самостоятельная репетиция диалога по печатным репликам. Сервер отводит
  две минуты на подготовку, затем девять на ответы и самопроверку.
  Запись добровольная, одна для трёх ответов; до конца подготовки она
  недоступна. Прогоны первых четырёх версий сохраняют одно задание и три минуты.

В обоих рекордерах после отключения микрофона восстанавливается режим
воспроизведения AudioSession для iPhone, а готовый клип повторно загружается
без mute. Регрессии покрывают MP4, отказ в разрешении и браузеры без API;
физическая проверка записи и звука на iPhone ещё требуется.

Bearer-only операции мобильного API защищены атомарными per-user лимитами в
Supabase: при превышении возвращаются `429` и `Retry-After` без обращения к
целевому storage. Закрытая таблица в `private` schema недоступна Data API;
при временной недоступности RPC остаётся instance-local best-effort fallback.

Состояние server-rendered урока (текущий шаг и счёт) подписывается Django,
ограничено по времени и привязано к пользователю, уроку и типу задания.
Подмена скрытых полей браузера не может увеличить сохранённый результат.

Проект остаётся на Supabase Free. Платная проверка утёкших паролей через
HaveIBeenPwned недоступна на этом тарифе, поэтому соответствующий security
advisor принят как известное ограничение; серверная политика защищает новые
регистрации, но не выдаётся за полную замену проверки утечек. Авторизованный
пользователь может сменить пароль с подтверждением текущего; после изменения
локальная сессия завершается и требуется повторный вход.

Read-only production smoke основных публичных и авторизованных API запускается
командой `python manage.py production_smoke <https-base-url>` с короткоживущим
токеном только в `POLSKIFLOW_SMOKE_ACCESS_TOKEN`; команда не изменяет данные и
не выводит токен или пользовательские payload.
