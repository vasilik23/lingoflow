# LingoFlow

Приложение для ежедневного изучения польского: короткий план на сегодня,
связанные уроки, чтение, словарь и подготовка к B1. Интерфейс и поддержка
материалов доступны на русском, польском и английском.

**[Открыть приложение](https://lingoflow-learn.vercel.app)** ·
[План работ](#единый-план-работ) · [История изменений](docs/project-history.md)

## Что можно делать

- Заниматься по дневному плану и сохранять прогресс в аккаунте.
- Изучать темы A1–C2: слова, грамматика, упражнения и тексты с разбором.
- Сохранять слова из чтения и повторять их по SM-2.
- Тренировать письмо, аудирование и речь; слушать файловую польскую озвучку.
- Готовиться к B1: отдельные навыки, учебный прогон пяти частей и письмо
  на 75 минут. История сохраняет агрегаты; самооценка не является баллом экзамена.
- Использовать адаптивный web/PWA, экспортировать данные и управлять аккаунтом.

Живой ИИ-пилот, независимая редактура и подписанный мобильный выпуск требуют
отдельной приёмки. Наличие материалов всех уровней не означает завершённую
независимую проверку их качества.

Оформление использует [единую нейтрально-зелёную палитру](docs/design-system.md)
со светлой и тёмной темой. История выполненного вынесена отдельно.

## Стек и структура

Production — Python/Django, Templates и HTMX в `backend/`.
Supabase предоставляет PostgreSQL, Auth и RLS; GitHub Actions и Vercel — CI и выпуск.
Node.js используется для проверок браузерной логики и операторских инструментов.

```text
backend/                Django: приложение, шаблоны, стили и тесты
supabase/migrations/    последовательные изменения production-базы
mobile/                 отдельный Expo-клиент в подготовке к beta
ops/                    аудит, мониторинг и инструменты восстановления
docs/                   инструкции, приёмки и история
```

## Быстрый запуск

Для новой локальной среды:

```bash
cd backend
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.lock
cp .env.example .env.local
python manage.py migrate
python manage.py runserver
```

По умолчанию используется SQLite. Для Supabase Auth задайте локально
`SUPABASE_URL` и `SUPABASE_ANON_KEY`; для PostgreSQL — `DATABASE_URL`.
Секреты не должны попадать в Git. Если среда уже настроена в IDE, используйте
её интерпретатор. [Полная настройка backend и Vercel](backend/README.md).

Перед публикацией:

```bash
cd backend
.venv/bin/python manage.py test
.venv/bin/python manage.py check
.venv/bin/python manage.py makemigrations --check --dry-run
```

Изменения Supabase применяются по порядку миграций с проверкой RLS и grants.
[Подробности запуска, маршруты и эксплуатационные ограничения](docs/project-history.md#основные-маршруты).

## Единый план работ

Единственная актуальная очередь. Каждый срез включает реализацию, проверку,
публикацию и обновление этой таблицы. Внешние приёмки не закрываются по автотестам.

| Приоритет | Результат | Следующее действие | Зависимость / критерий готовности |
| --- | --- | --- | --- |
| **P1** | Проверенные три учебных пилота · BM-01/02 | Передать [пакет редактору](docs/pilot-editorial-review.md): «Знакомство», «Жильё и услуги», «Биография и опыт» | Независимая оценка достижимости цели, польских формулировок, объяснений, distractors и самостоятельного ответа |
| **P1** | Понятный учебный маршрут · PA-04 | С учениками пройти выбор навыка → поиск темы → занятие → ошибку → результат → повторение по [сценарию](docs/product-audit-2026-10-16.md#следующая-человеческая-приёмка-pa-04) | Измерить успех и помощь, проверить нахождение справки и понимание самооценки; исправить препятствия до расширения пилотов |
| **P1** | Юридическая готовность | Заполнить данные контролёра и сроки хранения по типам данных | Решения владельца; широкому запуску предшествуют юридическая, языковая и техническая приёмки |
| **P1** | Проверенная доставка alerts | С явного согласия оператора выполнить [ручной тест](docs/alert-delivery-test.md), затем настроить внешний канал | Фактическое получение оператором; workflow и успешный scheduled-run этого не доказывают |
| **P1** | Настоящее восстановление backup | Снять копию, восстановить disposable-цель по [протоколу](docs/backup-restore-drill.md), сверить Auth и 17 learner tables, данные и RLS | Docker/PostgreSQL и локальный пароль БД; проверить расшифровку и отдельное хранение копии |
| **P1** | Принятая закрытая beta | Провести [beta](docs/closed-beta-readiness.md), assistive-technology/user audit, собрать согласованные наблюдения и field performance | Достаточный трафик, калибровка правил по данным, критерии готовности; физическая AT-проверка остаётся отдельной |
| **P2** | Независимая PL/EN-приёмка · PA-01/02 | Начать с A1–A2; проверить диагностику, письмо/речь, экзамены, динамические сообщения, публичный вход и демо | Редактор; [языковые критерии](docs/product-audit-2026-10-10.md), исправления отдельных строк не заменяют приёмку |
| **P2** | Проверенный живой ИИ | Настроить серверный Groq-ключ/флаг для [письма](docs/ai-writing-pilot.md), сравнить с преподавателем; затем проверить [речь](docs/ai-speaking-pilot.md) в Safari | Преподаватель, ключ и тестовый аккаунт; отдельный opt-in, отзыв согласия и защита от старых ответов; текущая приёмка не покрывает выключенный пилот |
| **P2** | Сохранность старых локальных данных · P2-08 | На аккаунте пользователя старого домена проверить черновики, записи и повторный вход по [плану переноса](docs/improvements-2026-10.md) | Нужен реальный старый браузер; до проверки не очищать данные старого сайта |
| **P3** | Подписанный мобильный клиент | Войти в Expo, связать EAS, настроить preview-окружение, пройти `build:check`, build и acceptance-smoke iOS/Android | Expo-проект, подпись и устройства; [команды](docs/mobile-beta.md) |
| **P3** | Первый редакторский выпуск темы | Выполнить ручной promotion receipt перед дальнейшей автоматизацией | Approval, verification, rollback evidence и права на материалы; [программа](docs/content-roadmap.md), [источники](docs/content-sources.md) |
| **P3** | Принятые напоминания на iPhone/PWA | Проверить opt-in, отключение и повторное открытие [foreground-канала](docs/browser-reminders.md) | Физический iPhone/PWA; это отдельная проверка от уже принятого аудио |
| **P3 · после beta** | Ограниченный авторизованный offline | Подготовить threat model и спроектировать кэш | Квоты, изоляция пользователя, logout purge и стратегия конфликтов |
| **P3 · после beta** | Адаптация по наблюдаемым результатам | Развивать план по beta-данным; учесть выполненную дневную цель в напоминаниях · RA-05 | Измеримые результаты; эвристики не выдавать за подтверждённый уровень |
| **P3 · после beta** | Push с проверенным согласием | Добавлять после стабильной доставки | Consent/delivery audit |
| **P3 · по решению владельца** | Собственный домен | Выбрать адрес и бюджет, подключить, повторить приёмку переноса | До решения использовать текущий `vercel.app` |
