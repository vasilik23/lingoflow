# Единый пакет редакторской проверки трёх пилотов

Команда `pilot_review_packet` собирает «Знакомство» A1, «Жильё и услуги» A2
и «Биография и опыт» B1 в автономные RU/PL/EN-страницы. Источник — только
активные учебные таблицы настроенной Django-БД и существующие переводные
каталоги. Аккаунты, ответы учеников, записи, прогресс и токены не читаются.
Команда ничего не публикует и не присваивает approval.

## Состав

- 15 уроков в порядке пилотного маршрута; чтение перед comprehension-проверкой.
- 45 карточек с примерами; 56 вопросов с вариантами, правильным ответом
  и объяснением; три чтения и глоссария. Ключ вопроса — `lesson_id:q:position`,
  без зависимости от различающихся SQLite/Postgres auto-increment IDs.
- Цель, ситуация, собственный ответ, чеклист и пример; исходная provenance.
- Локализованная поддержка через те же template filters, что в приложении;
  на EN добавлен существующий полный перевод чтения. Неизвестные/непереведённые
  фрагменты не объявляются проверенными автоматически.

Все шесть файлов находятся в одном новом каталоге:

| Файл | Назначение |
| --- | --- |
| `review-ru.html`, `review-pl.html`, `review-en.html` | Самостоятельные страницы с ответами для редактора; открыть локально, можно распечатать. JS, внешние CSS и сетевые запросы не нужны. |
| `snapshot.json` | Исходное содержание, заявленный code SHA, применённые content migrations и хеши переводов/renderer. |
| `review-notes.json` | Бланк reviewer, восьми критериев на каждую тему и findings; все оценки изначально `null`. |
| `manifest.json` | Размеры и SHA-256 пяти остальных файлов, checksum снимка, `not_reviewed` и `release_authorized=false`. |

Контрольная сумма связывает содержание и зависимости переводов, но не доказывает
естественность польского, соответствие CEFR, чистоту рабочего дерева или равенство
локальной и production-БД. `--source-commit` задаёт оператор: это declared SHA,
а не автоматически проверенная Git-подпись. Не использовать старый packet после
изменения материала/перевода; сформировать новый и дать редактору его checksum.

## Сборка

1. Выбрать чистый проверенный commit и актуальную изолированную Django content-БД.
   Не обновлять пользовательскую локальную БД ради экспорта. Неприменённые
   миграции, отсутствующий урок/чтение, неверный reading-check link, пустой урок
   или некорректный answer index останавливают экспорт до записи файлов.
2. Из `backend/` использовать Python проекта, выбранный PyCharm:

   ```text
   <PYTHON_PROJECT> manage.py pilot_review_packet --source-commit FULL_GIT_SHA --output-directory /private/tmp/lingoflow-pilot-review
   ```

   Каталог должен быть новым, его родитель уже должен существовать. Вывод внутри
   репозитория и перезапись запрещены. Каталог создаётся `0700`, файлы — `0600`,
   manifest записывается последним. Незавершённый каталог без manifest не является
   полным пакетом. Экспорт не выполняет migrations и не подключает внешние сервисы.
3. До принятия изменений production-материалов отдельно подтвердить соответствие
   снимка целевой базе. Этот инструмент не копирует production и не снимает backup.

## Передача редактору

Открыть HTML подходящего языка; сверять цель с каждым этапом, естественность
польского, переводы, единственность ответа, объяснения, чтение/глоссарий,
самостоятельный ответ и источники. В `review-notes.json` указать reviewer и
findings с точным `topic/lesson/question ref`, проблемным фрагментом,
обоснованием и предложенным исправлением. Отсутствие замечаний в незаполненном
файле не означает approval. Формат заметок не импортируется в progress или
promotion workflow; обычная проверка и promotion receipt остаются отдельными.

Пакет содержит ключи ответов. Не размещать его как публичную страницу урока;
отправлять редактору отдельно по согласованному каналу. Инструмент не отправляет
сообщений и не меняет права доступа в приложении.

## Проверено 16 октября 2026

Сборка из отдельной мигрированной SQLite: все три темы, 15 уроков, 45 карточек,
56 вопросов. Девять автономных layouts RU/PL/EN × 320/768/1440 px — без
горизонтального overflow, JS-ошибок и HTTP-запросов; навигация по темам работает.
Тесты покрывают отсутствие learner SQL и записей, изменение checksum при правке
содержания, HTML escaping, неполный источник, запрет перезаписи и приватные права.

Во время внутреннего просмотра исправлены четыре английские метки B1:
переезд, начало карьеры, достижение цели и важное событие. Они проверены в
настоящих локальных flashcard-формах на мобильной ширине без завершения урока
или production-записей. [Словарные основания](content-sources.md).
Это не независимая приёмка BM-01/BM-02 или PA-01/PA-02.

Release baseline: 1076 Django-тестов, system check, migration drift,
актуальность английского browser catalogue и diff check пройдены.
