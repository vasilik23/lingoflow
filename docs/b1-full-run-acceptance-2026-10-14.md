# Полный путь B1: итог и следующий шаг · 14.10.2026

Итог по пяти частям находится перед подробными разборами. После завершения
показана одна рекомендация: практика части с самым низким результатом ниже
учебного ориентира 50%, затем пропущенная часть; если таких частей нет —
короткий план B1. При одинаковом результате сохраняется порядок частей.
Для грамматики используется ссылка на теорию первого ошибочного или
пропущенного вопроса из существующего разбора. Старые итоги без ответов
ведут в каталог грамматики. Самопроверка письма и речи не получает балла.
Рекомендация не записывает новый прогресс и не назначает серверное повторение.

Исправлен найденный в браузере `ERR_CACHE_MISS` при Back из практики:
восстановленный POST заменяется записью истории GET после успешного сохранения
подписанного состояния в sessionStorage. При отказе storage история не меняется.
Основной переход использует общую кнопку приложения. Пояснение с `50%`
переводится через `ui_text`: gettext-ключ с обычным знаком процента раньше
не совпадал с автоматически экранированным ключом шаблонного `translate`.

## Проверки

- 1049 Django-тестов, system check, migration drift и `git diff --check`.
- Новый сквозной регрессионный сценарий для всех трёх вариантов: пять частей,
  timeout с частичными ответами в трёх проверяемых частях, самопроверка письма,
  пропуск речи, resume после каждой части, все разборы, отказ сохранения и
  успешная повторная запись без дублирования при дальнейшем resume.
  Хранилище истории в этом тесте подменено; это проверка контракта.
- Локальный Chromium на свежей временной базе: пять частей, частично заполненные
  выборы и письменная грамматика, отмена/подтверждение, refresh, оба черновика
  письма и их удаление после части, подготовка речи, итог и refresh итога.
  Перерывы и подготовка ускорены часами временного сервера, лимиты production
  не менялись. Supabase отключён: проверено честное сообщение о несохранении.
- Итог проверен в RU/PL/EN, светлой/тёмной теме, на ширинах 320/393/1440:
  один h1, отсутствие горизонтального переполнения, итог перед разборами,
  одна рекомендация без русского текста в PL/EN; переход и Back восстанавливают
  отчёт. Это 18 сочетаний, а не проверка физических устройств.
