# Production-приёмка обычным QA-учеником · 14.10.2026

## Аккаунт и границы

По разрешению пользователя зарегистрирован отдельный обычный ученик через
production `/register/`, с временным ящиком [Mail.tm](https://mail.tm/).
Роль `authenticated`, не anonymous; дополнительные app_metadata-привилегии
отсутствуют. Пароль, доступ к ящику и UUID находятся в игнорируемом локальном
`backend/.env.qa-20261014.local`, права 600. Секретов в Git нет.
Текущая регистрация сразу выдала подтверждённую сессию; настройки Auth не менялись.
Существующий `admin` по точному display_name или локальной части email не найден;
это не утверждение об отсутствии всех администраторов.

Временный аккаунт предназначен для разовой приёмки, не постоянного мониторинга.
Основные аккаунты и данные учащихся не менялись. Браузер — Chromium 393 px,
не физический Safari; результаты iPhone предоставлены пользователем отдельно
в [протоколе устройства](iphone-acceptance-2026-10-14.md).

## Fresh-session smoke

`production_smoke --fresh-session` прошёл все шесть production-проверок:
health, ready, OpenAPI, catalog, bootstrap, export. Вход — password grant
обычного ученика с publishable key; локальный logout проверен командой.
Токены не сохранялись в артефакты и не публиковались. Schedule не включался:
для него нужен устойчивый отдельный адрес оператора и environment Secrets.

## Найденный баг текущего дня

Реальная слабая попытка `bio-quiz` сохранила `0/10` в `lesson_completions`.
Строка проверена через Data API с токеном этого ученика и read-only SQL.
Однако маршрут темы не показывал закрепление: `load_dashboard_progress`
исключал текущий день из `recent_completion_results`.

Исправление включает сегодняшний день в проверенные результаты за 30 дней,
сохраняет фильтр будущих дат. Это также исправляет недельную точность.
Дневной план сам исключает уже выполненные сегодня задания и планирует
повторение не раньше следующего дня; это ограничение не изменено.
Регрессия покрывает 0/10 и 10/10, актуальный результат маршрута, недельную
точность и отсутствие повторного назначения выполненного урока в тот же день.
