# Три связанных сценария A1/A2/B1

BM-01/BM-02: технический пилот опубликован поверх существующих материалов.
Новых тем, меню, таблиц или способов начисления прогресса нет.

| Уровень / тема | Наблюдаемый результат | Связанные материалы |

| A1 · Знакомство | Представиться и задать два вопроса | words → grammar → review → «Pierwszy dzień na kursie» / a1read-kurs-check → quiz → собственный ответ |

Курс показывает практическую цель вместо общего описания и один вход в сценарий.
Отдельные уроки доступны в раскрываемом списке. Новый экран темы показывает одну
рекомендацию по результатам аккаунта и последовательность пяти сохранённых шагов.
Чтение считается пройденным после ответов на его вопросы, а не после открытия.
Последний самостоятельный ответ имеет три критерия и пример; он не отправляется,
не получает автоматический балл и не меняет прогресс. Его можно скопировать.

После успешного повторения фраз результат ведёт к чтению с готовым аудио;
после вопросов текста — к проверке темы; после успешной проверки — к своему ответу.
Ошибки ниже действующего порога 70% сохраняют существующую рекомендацию закрепить
материал. Сохранённый слабый результат приоритетен на экране темы, последующая
успешная попытка отменяет рекомендацию. Недоступное хранилище не обозначается
успешным сохранением и не отмечает шаги пройденными.

Новые цели, инструкции, рубрики и примеры — оригинальный редакторский материал
LingoFlow от 13.10.2026, ru/pl/en. Проверены связи, наличие объяснений и правильных
индексов; независимая польская редактура и PA-04 с учениками остаются открытыми.
При проверке обнаружено, что устаревшая локальная база содержала неоднозначный
вариант `przepracowała`: актуальная миграция 0098 и production уже исправили его.
Повторной миграции не требуется. Проверка переключена на свежую временную базу.
[WSJP PAN: значение przepracować](https://wsjp.pl/haslo/podglad/35557/przepracowac/4978736/pewien-czas)
использован только для проверки факта; его словарные тексты не импортировались.

Проверки: 1047 Django-тестов, check и migration drift; 54 раскладки ru/pl/en,
light/dark, 320/393/1440 и переходы курс → тема → урок / чтение → тема;
нативная клавиатурная самопроверка. Шесть полных подписанных quiz-попыток
в браузере: слабый/успешный результат для каждого пилота, ровно один followup
и честный статус несохранённого результата. Нет overflow или page errors.
