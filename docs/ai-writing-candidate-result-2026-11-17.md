# ИИ-письмо · первый кандидат остановлен 17 ноября 2026

Первый кандидатный промпт из [плана сравнения](ai-writing-candidate-plan-2026-11-17.md)
проверен на защищённом Vercel Preview, commit
`d54cb904818c316a29112358c1cc191abc6a3d0b`. Ключ и флаг ИИ
были ограничены только веткой кандидата. Один синтетический запрос
`class-error/RU` отправлен через штатный UI существующего QA с согласием,
общей квотой и теми же параметрами модели, что у baseline. HTTP 200,
4123 мс от отправки браузером, черновик сохранён. Это один ответ,
не полный прогон 24 пар и не доказательство частоты дефекта.

Модель снова заменила `na lekcja` на **`na lekcję`**, хотя в контексте
«быть на уроке» требуется **`na lekcji`**. Объяснение обобщило правило
«после na требуется винительный»; это неверно для данного контекста.
Та же неверная правка уже присутствует у baseline `class-error/RU`.
Следовательно, кандидат не устранил исходный критичный дефект в этом
контрольном случае. Остальные 23 пары для него не запускались, общий балл
кандидата не вычисляется. Точный ответ хранится только в приватном QA-артефакте,
в опубликованных файлах — категория и краткое воспроизводимое наблюдение.

После запроса read-only SQL показал **2/10** попыток в текущем окне QA
с началом 17 ноября 15:05:00 UTC; второй запрос — кандидатный.
Автоматических повторов, второго аккаунта и прямых вызовов провайдера не было.
Черновик [PR #430](https://github.com/vasilik23/lingoflow/pull/430) закрыт
без merge. Ветка Preview пересобрана с `GROQ_WRITING_ENABLED=false`;
Production-промпт, ключ и флаги не изменялись. Старый уникальный Preview URL
остаётся защищён Vercel Deployment Protection; адрес ветки указывает на
новую сборку с выключенной функцией.

Следующий кандидат должен проверять грамматическое управление в контексте
всей фразы и воздерживаться от непроверенного правила. Проверять его сначала
на уже найденном сбое и корректном контрпримере, затем на полном наборе
RU/PL/EN без обхода квоты. Одним prompt-дополнением качество не объявлять
принятым; после автоматического отчёта вручную читать весь совет.
