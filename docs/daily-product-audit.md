# Ежедневный аудит LingoFlow

На этом Mac зарегистрирован `com.lingoflow.daily-product-audit`: каждый день
в **09:00 по системному времени** (сейчас Europe/Warsaw) macOS запускает
`ops/daily-product-audit.mjs`. Это локальный LaunchAgent, а не GitHub cron
и не встроенная задача Codex App. Нужны включённый Mac, пользовательская
сессия, интернет и действующий вход в Codex CLI. Запуск расходует доступный
лимит текущего плана Codex; отдельный API-ключ не настроен.

При сне macOS может выполнить пропущенное календарное задание после
пробуждения. Выключенный компьютер не обеспечивает проверку в 09:00.
Изменение системного часового пояса изменит фактическое время запуска.

## Что проверяется

Runner вызывает [lingoflow-product-audit](../.codex/skills/lingoflow-product-audit/SKILL.md)
по [заданию](../ops/daily-product-audit.md): роли PO, Designer и QA,
production в браузере, мобильная/десктопная ширины, реальные сценарии,
известные findings и изменения за сутки. Авторизованные сценарии допускаются
только локально с синтетическими fixtures. Секреты и пользовательские данные
не читаются. Аудит не исправляет код, не меняет production, не отправляет
сообщения, не создаёт PR и не обновляет README автоматически.

Исходники берутся через `git archive HEAD` в отдельный временный снимок.
Незакоммиченные изменения, `.env` и локальная база не включаются.
Последний ежедневный отчёт передаётся следующему запуску для сравнения findings.
SHA снимка записан в отчёте; он может отличаться от текущего production,
если локальная ветка ещё не опубликована. Для анализа изменений runner
передаёт список коммитов и изменённых файлов за последние сутки.

Один запуск ограничен 15 минутами; второй одновременно не начинается.
Настоящий Safari, VoiceOver, микрофон iPhone, восстановление пароля по письму
и авторизованный production отмечаются как непроверенные, если доступа нет.
Созданный отчёт сам по себе не означает, что все проверки прошли.

## Где смотреть результат

Файлы находятся в игнорируемой Git папке `.local-audits/<UTC-время>/`:

- `report.md` — findings, доказательства, coverage и предложения для роудмапа;
- `status.json` — SHA, время и `report_created` либо `failed`;
- `evidence/` — сохранённые браузерные доказательства, если аудит их создал;
- `runner.log` — журнал Codex CLI;
- `failure.txt` — причина неуспешного запуска, если есть.

Журнал планировщика: `.local-audits/launch.log` и `launch-error.log`.
Каталоги запусков доступны только владельцу. Перед передачей отчётов другим
проверь содержимое: они предназначены для локальной работы.
Временный снимок удаляется после завершения. При аварийном выключении
могут остаться снимок и `.local-audits/running`: сначала проверь отсутствие
живого процесса, затем удали оставшийся lock, чтобы возобновить расписание.

## Управление

Проверить регистрацию:

```sh
launchctl print "gui/$(id -u)/com.lingoflow.daily-product-audit"
```

Запустить зарегистрированное задание сейчас:

```sh
launchctl kickstart "gui/$(id -u)/com.lingoflow.daily-product-audit"
```

Остановить расписание:

```sh
launchctl bootout "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.lingoflow.daily-product-audit.plist"
```

Вернуть расписание:

```sh
launchctl bootstrap "gui/$(id -u)" "$HOME/Library/LaunchAgents/com.lingoflow.daily-product-audit.plist"
```

Для ручного запуска из репозитория при наличии `node` и `codex` в PATH:

```sh
node ops/daily-product-audit.mjs
```

Можно задать абсолютный путь Codex через `LINGOFLOW_AUDIT_CODEX`.
Установленный plist использует абсолютные Node/Codex из текущего PyCharm.
После обновления IDE, смены пользователя или переноса проекта проверь
`ProgramArguments`, `WorkingDirectory`, `PATH`, `LINGOFLOW_AUDIT_CODEX`
и пути логов в `~/Library/LaunchAgents/com.lingoflow.daily-product-audit.plist`.
После изменения plist останови и вновь зарегистрируй задание.

Для нового Mac: сделай вход `codex login`, возьми
[пример plist](../ops/daily-product-audit.plist.example), замени все `__…__`
абсолютными путями, создай `.local-audits` с правами 700, проверь `plutil -lint`
и зарегистрируй файл в `~/Library/LaunchAgents` командой выше.
