# Бланк наблюдений · предварительный тест 3–5 человек

**Пустой шаблон, не результаты.** Скопировать вне Git; заполненную форму
хранит организатор в закрытом месте. Для передачи агенту убрать имя, email,
идентификаторы аккаунта и личные тексты. Секреты и session cookies не собирать.

| Контекст | Значение |
| --- | --- |
| Условная метка участника | P01–P05; соответствие человеку хранить отдельно |
| Добровольное участие 18+ подтверждено организатором | Неизвестно |
| Дата/время и часовой пояс | Неизвестно |
| Полный SHA проверяемого релиза | Неизвестно |
| Устройство, ОС, браузер | Неизвестно |
| Выбранный уровень и тема | Неизвестно |
| Номер сессии | День 1 / возвращение на следующий день |

Для каждого шага: **сам / с помощью / не получилось / не проверено**.
Записывать фактические действия, не домысливать непроверенное.

| Шаг | Результат | Затруднение / помощь |
| --- | --- | --- |
| Найти подходящее занятие и начать | Не проверено | |
| Ответить и понять объяснение ошибки, если она была | Не проверено | |
| Завершить урок и увидеть результат | Не проверено | |
| Обновить страницу: результат остался | Не проверено | |
| Найти следующий шаг / повторение, если предлагается | Не проверено | |
| Вернуться на следующий день: результат остался | Не проверено | |
| Начать занятие при возвращении | Не проверено | |

1. Где было непонятно?
2. Понятно ли, почему ответ неверный и что делать дальше?
3. Что одно исправить первым?
4. Хотелось бы продолжить? Почему?
