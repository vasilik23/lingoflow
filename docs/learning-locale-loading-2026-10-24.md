## Как сохраняются нужные сообщения

`build_ui_catalog` строит оба вида из одних MO. `runtime_catalog.py` сохраняет
ключи, встречающиеся где-либо в HTML/JS, включая таблицы строк и экранированные
литералы; все ключи с `%(v...)s`; явный динамический manifest
`localization/browser_messages.json`. Это консервативная проекция, не агрессивное
разделение по отдельным маршрутам. Generated `i18n-*` исключены из источников,
чтобы прежний файл не удерживал удалённые сообщения сам через себя.

При добавлении текста, собираемого из серверных данных или внешнего JSON,
его необходимо включить в динамический manifest либо использовать уже
локализованную серверную подпись. Отсутствующий в gettext manifest key блокирует
сборку. `--check` проверяет полноту/актуальность обоих generated файлов.

В письме приоритет повторения теперь берёт подпись из уже переведённого
`span` чекбокса. Значение checkbox и ключи localStorage не изменены;
произвольный серверный label не требует загрузки всех переводов в браузер.

```text
<PYTHON_PROJECT> manage.py build_ui_catalog --language pl
<PYTHON_PROJECT> manage.py build_ui_catalog --language en
<PYTHON_PROJECT> manage.py build_ui_catalog --language pl --check
<PYTHON_PROJECT> manage.py build_ui_catalog --language en --check
```

## Проверки и полный урок

- **1191 Django-тест**, system check, migration drift — PASS. Четыре новых
  регрессии проекции: literal/table/escape/dynamic, неизвестный manifest,

  B1/B2 loading/playing/ended/stop подписи настоящими runtime-каталогами.
- 12 сочетаний RU/PL/EN × light/dark × 320/1440: **24 полных урока A2/B1,

  проверены отдельным SQLite-запросом; повтор ошибки не переписывает балл урока.
  0 pageerror/overflow. Это изолированный стенд с подменённым Auth/repository.
- Ещё 3 браузерных случая RU/PL/EN: счётчик письма, проверка структуры,
  локализованная подпись выбранного приоритета, 3 полных B1-урока с результатом
  SQLite и видимый таймер экзамена.
- В этих трёх уроках записаны только method/status/duration для **45 HTTP 200**:
  GET n=3, p50/p95 до заголовков 30/53 мс; POST n=42, 34/55 мс.
  Django app p50/p95: GET 27/48 мс, POST 31/49 мс. POST включает переходы
  между вопросами и refresh результата. Это локальный учебный маршрут с
  фикстурным хранилищем, **не latency production Supabase** и не cohort beta.
- Дополнительный harness исправлен после принудительного checkbox click
  и отсутствия обработки задания sentence builder. Неуспешные попытки harness
  не объявляются регрессиями продукта; успешный проход выполнен обычными кликами.
