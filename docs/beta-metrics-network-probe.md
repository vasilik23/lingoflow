## Повторный операторский запуск

Локальный `backend/.env.metrics-probe.local` — owner-only 0600, вне Git, читается
только операторской командой и не включает сбор Django. На этом компьютере
нужен доверенный CA bundle: `SSL_CERT_FILE=/etc/ssl/cert.pem`; проверка TLS не
отключалась. Начальные ошибки отсутствующего Python CA не считались успехом.
Новые `sb_secret_…` передаются только в `apikey`, legacy service-role JWT — также
в Bearer, согласно [контракту Supabase](https://supabase.com/docs/guides/getting-started/api-keys#known-limitations).

`manage.py beta_metrics_network_probe --release FULL_PRODUCTION_SHA --runs 5`
проверяет nonmember; `--context qa` читает ID только из приватного QA-файла.
Перед записью оператор проверяет membership, создаёт отдельную временную
когорту и после проверки удаляет её вместе с observations. Сам инструмент
не зачисляет участников. Временный QA Preview уже удалён и не переиспользуется.
