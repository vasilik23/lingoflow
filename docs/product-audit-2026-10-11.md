# Упрощение LingoFlow — PO / Designer / QA, 11.10.2026

Основание: пользователь сообщил, что реальные ученики считают приложение
слишком сложным. Исходных интервью и записей сессий нет: причины ниже —
наблюдения аудита, а не приписанные пользователям высказывания.
Базовый commit: `0c2187a1fe1758d2c3ed71fa5f4c97e6a9218a75`.

## Покрытие и ограничения

Chromium, локальный Django, изолированный SupabaseUser `browser-fixture`;
проверка исходных страниц на 390/1440 px, без реальных аккаунтов и записей.
Локальная база — ранний снимок; недоступность Auth/store в fixture не считается
production-багом. RU: Сегодня, Курс, Практика, Чтение, письмо B1, подготовка B1,
Профиль — осмотр структуры и доступных действий, не завершение сценариев.
Production: публичные `/`, `/demo/`, `/login/` — только чтение страниц.
После исправлений: Курс/Практика RU/PL/EN, 320/390/1440 px, light/dark;
клавиатура, resize, прямая ссылка на тему, refresh, запуск урока и Back.
Не проверены: сохранение результата в реальном аккаунте, полный B1-прогон,
ошибки сети/store, истечение таймера, privacy/security операции, микрофон,
физический Safari iPhone/Mac и VoiceOver. Это пробелы проверки, не новые баги.

## Основания и выпуск

[Nielsen: minimalist design, recognition, consistency](https://www.nngroup.com/articles/ten-usability-heuristics/)
поддерживает приоритет главного действия и понятных названий; это эвристики,
а не сертификация. [WCAG 2.2: keyboard и headings/labels](https://www.w3.org/TR/WCAG22/)
используется для проверки раскрытия тем и названий, без заявления соответствия
всего приложения WCAG.

SIM-01/SIM-02 не удаляют материалы, не меняют данные, оценивание или маршруты.
Проверка выпуска: Django tests, system check, migration drift, git diff --check;
36 layout-проверок и клавиатурные сценарии RU/PL/EN. Экзаменационные P1
(реальные записи диктора, ручная оценка, устройства) и существующие P0 сохраняются.

## SIM-05 — техническая реализация 12.10.2026

Письмо A1–C2: задание → черновик → одна проверка → один следующий шаг.
Уровни, ориентир, подробная самопроверка и удаление свёрнуты; пример доступен
после проверки, ИИ остаётся добровольным отдельным раскрытием. Закрепление
появляется после отметки языковой ошибки и предлагает один урок.
Выбор задания сохраняется в account/level-localStorage; черновики и прежние
отметки требований/языковых ошибок сохраняют существующие ключи. Изменение
текста скрывает старый результат. Подсказка по объёму/абзацам/маркерам не
оценивает грамотность; подключение ИИ и правила согласия не менялись.
Базовый commit — `89cfc30a141291b5cd5500a2bb347ffc3273fb97`.
1023 теста, 54 Chromium layouts A1–C2 RU/PL/EN (320/390/1440): проверка,
refresh/Back, draft/selection/error marks, reset cancel/confirm; отдельно
Storage failure не блокирует проверку и честно сообщает отсутствие сохранения.
Auth fixture, ранний локальный снимок, синтетические тексты. Живой ИИ,
production persistence и реальная пользовательская приёмка не проверены.
Следующий пункт — SIM-06; приёмка эффекта всех упрощений остаётся открытой.
