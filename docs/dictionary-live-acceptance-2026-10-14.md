# Словарь: живое сохранение и язык поиска · 14.10.2026

## Проверка production

Обычный QA-ученик из предыдущей приёмки, без административных прав.
В Chromium 393 px выполнены восемь обычных сохранений через страницы чтения:
четыре слова/выражения в PL, затем те же четыре в EN.

| Форма в тексте | Сохранённая лемма | Чтение |
| --- | --- | --- |
| dorastała | dorastać | bio-droga-joanny |
| punktem | punkt zwrotny | bio-droga-joanny |
| przyzwyczaić | przyzwyczaić się | bio-droga-joanny |
| wynajmuje | wynajmować | usterka-w-mieszkaniu |

Data API с токеном самого ученика и read-only SQL подтвердили четыре строки,
без дублей. Исходные переводы сохранены, несмотря на PL/EN интерфейс.
После локального logout и нового входа словарь содержит те же четыре записи.
Настоящий `GET /api/v1/me/export/` вернул их с исходными переводами и без
внутреннего поля `display_translation`. Пароль и токены в Git не добавлялись.

## Найденное и исправленное

Сохранённое `dorastać` отображалось как “grow up”, но поиск по “grow up”
возвращал ноль строк: проверялся только исходный русский перевод.
Представление словаря теперь вычисляет отображаемый перевод один раз и
использует его для вывода и поиска. Поиск по польской лемме, исходному переводу
и контексту сохранён. Исходные словари не мутируются; запись/экспорт/проверка
ответов используют прежние данные. Изменений схемы или RLS нет.

Семь английских глосс уточнены: speak, introduce oneself, acquire,
completion; ending, school-leaving exam, rent, according to. Это исправления
коротких собственных меток, не новая версия польских материалов и не
независимая редакторская приёмка. Источники проверки смысла —
[реестр](content-sources.md#глоссы-пилотов-и-поиск-словаря--14102026).

## Проверки и оставшиеся границы

- 1053 Django-теста, system check, migration drift, diff check.
- Регрессии поиска по отображаемому английскому переводу, исходному русскому,
  польской лемме и форме в контексте; сохранение исходных словарей без мутации.
- 54 локальных раскладки поиска: RU/PL/EN × light/dark × 320/393/1440 ×
  три запроса. Проверены один h1, результат поиска и отсутствие переполнения.
- Шесть глосс проверены непосредственно в панели чтения; скрытая форма сохранения
  продолжает отправлять исходный перевод, а не отображаемый английский.
- Физический VoiceOver, переключение голоса и независимая языковая редактура
  остаются открытыми. Это не проверка всех форм всех чтений.
