# Редакторский пакет: сверка с production

19 октября выполнена техническая сверка трёх пилотов с опубликованными
учебными таблицами Supabase. В production выполнен только один SELECT
по содержимому; аккаунты, ответы, записи и прогресс учеников не читались.
[SQL-проекция](../ops/pilot-review-parity.sql) сохраняет порядок вопросов
и карточек и исключает неактивные материалы.

## Найдено и исправлено в локальном пакете

Первоначальный экспорт из Django seeds не полностью совпадал с production:
описание `a1read-kurs-check` отличалось, а в глоссарии `pierwszy-dzien-na-kursie`
не хватало `mieszka` и `pochodzi`. A2 и B1 совпали.

Изменены только описание и глоссарий в изолированной SQLite для экспорта.
Production и исходные миграции не менялись. Оригинальный пакет сохранён;
новый экспорт сверён повторно по всем полям проекции.

| Проверка | Результат |
| --- | --- |
| Активные темы и уровни | 3/3 совпали |
| Уроки | 15/15: ID, тип, заголовок, описание, теория и metadata |
| Вопросы | 56/56: стабильный ref, формулировка, порядок вариантов, ключ и объяснение |
| Карточки в маршрутах | 45/45: ID, польское слово, перевод, пример и metadata, с сохранением порядка |
| Чтения | 3/3: заголовки, все абзацы, исходный глоссарий и metadata |
| Переводы и renderer | Хеши 10 зависимостей экспорта совпали с Git-версией `6293c59a46b551143bbb9385f94d91805775ccd5` |
| Целостность | Размеры и SHA-256 пяти payload-файлов совпали с manifest |

Порядок маршрута, ситуации, цели и образцы берутся из связанной Git-версии,
а не из БД. Техническое совпадение не подтверждает естественность языка,
методическую пригодность или достижимость цели учеником.

## Актуальный пакет для передачи

Папка вне Git: `../lingoflow-editorial-20261019-production/` в Documents рядом
с проектом. Содержит автономные `review-ru.html`, `review-pl.html`,
`review-en.html`, `snapshot.json`, `review-notes.json`, `manifest.json`
и отдельный `production-parity.json`. Папка — `0700`, файлы — `0600`.

Snapshot SHA-256:
`a65b24e703d8f0df3a1de6566b0f44a6ff152d863e8542209a531a223067913f`.

Sidecar связывает этот snapshot с исходным manifest и результатом сверки.
Базовый экспорт сохраняет консервативную формулировку о непроверенном источнике;
доказательство сверки конкретного пакета находится отдельно. Исходные файлы
не редактировались после формирования manifest.

`not_reviewed` и `release_authorized=false` сохранены. Сверка подтверждает
состояние содержимого на момент запроса, а не будущую неизменность production.
При новой редактуре или изменении источника нужна новая сверка и новый пакет.
Следующее действие — передать его независимому редактору с
[рабочим листом](pilot-editorial-worksheet.md). Автоматической отправки не было.
