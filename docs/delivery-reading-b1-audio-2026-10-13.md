# Файловое аудио чтения и B1

Пакет заменяет системный синтез речи в 70 чтениях A1–C2, полном учебном
B1-прогоне, mini-mock и тренировке отдельного аудирования. Используется
локально синтезированный Piper pl_PL-bass-high в AAC. Файлы отвечают точному
оригинальному польскому тексту; язык интерфейса не меняет озвучку.

Manifest хранит контрольные суммы текста, файла и модели. Изменённое чтение
не получает устаревший файл; B1 сохраняет прежний fallback только для текста,
для которого нет подходящего синтетического файла. В полном прогоне проверенная
запись диктора имеет приоритет. При исчезновении закреплённой записи прогон не
подменяет её синтетическим файлом. Расширенный комплект блоков по-прежнему
требует полного набора проверенных записей.

Чтение: слушать, пауза, продолжение с прежней позиции, остановка, скорость.
Без JavaScript доступны обычные controls HTML audio. При уходе со страницы
воспроизведение останавливается. B1: два фактически начатых прослушивания,
30-секундная пауза, восстановление счётчика, общий deadline; ошибки запуска
не тратят попытку. Перед запуском применяется общий AudioSession playback.

Новых миграций, API-ключей, TTS-зависимостей в production и передачи текста
внешнему сервису нет. Реестр источников фиксирует модель и декларацию лицензии.
Произношение, естественность и silent mode на физическом iPhone требуют
отдельного прослушивания; браузерная автоматика их не подтверждает.

Проверки перед публикацией:

- 1041 Django-тест; system check и migration drift — успешно.
- Все 70 чтений из свежей базы актуальных миграций совпали с входом синтеза;
  все 73 файла совпали с SHA-256 манифеста, декодированы и содержат ненулевой звук.
- 54 раскладки A1/B1/C1: RU/PL/EN, light/dark, 320/393/1440 px — один h1,
  без горизонтального переполнения и ошибок страницы; запуск/пауза/продолжение,
  скорость и остановка работают без SpeechSynthesis.
- Три B1-режима: реальный запуск файла, остановка и сохранение ограничения
  после refresh. Node-регрессии проверяют два запуска, cooldown, ошибки и deadline.
- Шесть раскладок чтения без JavaScript с native controls; реальный отказ
  загрузки и повтор, 10-секундный timeout зависшей загрузки, Back без autoplay.

Браузерная проверка выполнена в Chromium на локальном fixture-аккаунте.
Production-история реального аккаунта, микрофон и физические Safari не проверялись.
Возобновление сборки: `--progress-manifest` сохраняет атомарные checkpoints;
`--resume-manifest` принимает только ту же модель, настройки, текст и SHA файла.
