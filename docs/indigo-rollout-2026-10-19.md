# Indigo · перенос выбранного оформления

Владелец выбрал предварительный вариант 19 октября. Общие CSS-токены заменены
во всём Django-приложении; шрифт и сохранение выбора темы оставлены прежними.
Нейтральные фон, поверхности, основной и второстепенный текст больше не имеют
зелёного оттенка. Сине-фиолетовый используется для действий, навигации,
выбранных ответов и прогресса. Зелёный отделён от акцента и обозначает успех.

Обновлены также автономные offline/editorial страницы, browser theme-color,
manifest и SVG-иконка PWA. Успешный статус использует свой цвет текста на
зелёном фоне; нейтральные уведомления и обычные ссылки не стали зелёными.

В исходниках Expo-клиента применяется та же палитра. Добавлены `onPrimary`,
`selected`, `success`: подписи и индикаторы на светлом акценте тёмной темы
получают тёмный цвет, выбранные варианты — фон и рамку. Новую подписанную
native-сборку этот веб-релиз не создаёт.

| Проверка | Результат / граница |
| --- | --- |
| Django | 1116 тестов; system check и migration drift check |
| Общие токены | Точные цвета обеих тем, контраст текста, ошибок, успеха, кнопок, hover, полей и focus; самостоятельные шаблоны сверяются с основной палитрой |
| Страницы | 21 маршрут × light/dark × 390/1440 = 84 проверки; нет текстовых contrast failures, недостаточного контраста границ полей и горизонтального overflow |
| Реальные состояния | B2 exercise/answer review, hover/focus/disabled, writing dialog + Escape и offline: обе темы, 320/1440; без ошибок JS |
| Mobile source | `npm run verify`: config, 6 build-readiness tests, TypeScript; повторный typecheck |
| Внешние ограничения | Физический Safari, screen reader и native build не проверены этим срезом; ранее принятую проверку аудио не переоткрывали |

Проверки страниц используют локальную fixture-auth и отдельную SQLite,
а не production-аккаунты. Offline/editorial палитры встроены в автономный HTML,
чтобы они работали без загрузки CSS; тест сверяет их с основными токенами.
Настоящие записи пользователей и production-схема не менялись.

## Параллельный следующий P1

Подготовлен [рабочий лист независимого редактора](pilot-editorial-worksheet.md)
для трёх учебных пилотов: точные маршруты 15 уроков и трёх чтений, восемь
критериев, формат замечаний, решения pass/change/blocked и повторная приёмка
по версии snapshot. Инструкция передачи связана с этим листом.

Это завершённая подготовка к проверке, а не независимая редакторская оценка.
Она остаётся следующей задачей в README: нужны редактор, согласованный канал
и актуальный снимок целевой БД. Пакеты и сообщения никому не отправлялись.
