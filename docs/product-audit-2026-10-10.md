## Среда и границы

Production `https://lingoflow-learn.vercel.app`: только публичные страницы и
синтетический ответ в гостевом B1-демо, без записи в аккаунт. Приватные страницы:
локальный Django, Chromium через agent-browser; подменена только авторизация
на фиктивного пользователя, Supabase URL/key пусты. Данные курса — локальные.
Недоступность личного прогресса/словаря в этой среде **не является production-багом**.
Скриншоты локальных курса/практики просмотрены; состояние — тёмная тема.

Initial-layout проход: 320/1440 px локально, 390 px публично. Урок дополнительно
проверен на RU/PL/EN с ответом и Tab; это не полная проверка всех переводов.
Нет переполнения на измеренных initial-layout экранах и нет найденных browser
errors. Проверка подписей полей — DOM-эвристика, не полный accessibility audit.
Не измерены contrast/zoom/light theme, не проведены пользовательское исследование,
VoiceOver, физические Safari/iPhone, микрофон, offline/потеря сети/таймер,
production-персистентность, каскады удаления и реальные письма восстановления.

## Подтверждённые дефекты

### PA-01 · P1 · PO / QA · русский материал в польском интерфейсе

**Доказательство:** local, PL. `/lesson/quiz/` показывает «Как неформально
поздороваться?», после ответа — «Cześć — неформальное приветствие…» рядом
с польскими `Niepoprawnie` и `Następne pytanie`. EN переводит этот же материал.
Наблюдение достоверно для этого урока; объём остальных непереведённых материалов
требует инвентаризации, production-приватный пример не проверен.

**Воспроизведение:** выбрать PL → открыть обычный quiz → ответить на первый
вопрос. **Ожидание:** инструкции/разбор на выбранном языке, польские упражнения
сохраняют польский оригинал. **Фактически:** русские prompt/explanation.
**Причина в коде:** [learning_text](../backend/polskiflow/learning/templatetags/ui.py)
применяет перевод только при `en`; [question](../backend/templates/lessons/_question.html)
использует этот фильтр для prompt/explanation.

**Предложение:** инвентаризировать PL study-support, подключить проверенные
польские инструкции/объяснения, сохранив языковую задачу упражнения.
**Приёмка:** первый A1 quiz и репрезентативные grammar/words B1 не содержат
русской поддержки при PL; RU/EN не регрессируют; оригинальные польские ответы
не превращаются в перевод. Автотесты + независимая языковая проверка.
**Усилие:** M–L; каталог переводов и редакторская проверка. Это не только CSS.
Основание: последовательность интерфейса и соответствие пользовательской задаче
([NN/g](https://www.nngroup.com/articles/ten-usability-heuristics/)).

### PA-02 · P2 · Designer / QA · неверный язык учебных фрагментов для AT

**Доказательство:** RU-reader `/reading/pierwszy-dzien-na-kursie/`: абзац
`To jest pierwszy dzień Anny…` имеет ближайшего предка `[lang]` — `html lang="ru"`.
В quiz польские варианты также наследуют язык UI; в PL русский prompt наследует
`pl`. Проверены DOM и исходные шаблоны; реальное неправильное произношение
VoiceOver ещё не измерено.

**Воспроизведение:** RU → первый учебный текст → проверить язык `.reading-paper p`.
**Ожидание:** польский оригинал размечен `lang="pl"`, поддержка — своим языком.
**Фактически:** у польского оригинала отсутствует language override.
**Источник:** [reader](../backend/templates/reading/reader.html),
[lesson question](../backend/templates/lessons/_question.html).

**Предложение:** обозначить язык польских текстов, слов/вариантов ответа и
смешанной поддержки на уровне конкретных фрагментов; не назначать всему
вопросу `pl`, если инструкция русская/английская.
**Приёмка:** ближайший `[lang]` оригинального абзаца/польского слова — `pl` в
RU/EN; поддержка соответствует RU/PL/EN; проверить переключение голоса с
VoiceOver на физическом устройстве. **Усилие:** S–M; смешанные строки сложнее.
Основание: [WCAG 2.2, 3.1.2 Language of Parts](https://www.w3.org/TR/WCAG22/#language-of-parts).
Spot audit не является заключением о соответствии всего приложения WCAG.

## Предложения — не подтверждённые функциональные баги

### PA-03 · P3 · Designer / QA · основной заголовок quiz

Local `/lesson/quiz/`: `h1` отсутствует, prompt — `h2`, название урока — `strong`.
У страницы корректный document title; отсутствие `h1` само по себе не доказывает
нарушение WCAG. Предлагается один основной heading в shell урока и согласованная
иерархия вопроса/разбора. Приёмка: один осмысленный основной заголовок, переход
по heading доступен, title и компактная шапка сохраняются. Усилие S.
[WCAG 2.4.6](https://www.w3.org/TR/WCAG22/#headings-and-labels) — критерий смысла
заголовков, а не обязательного конкретного числа `h1`.

### PA-04 · P2 · PO / Designer · первый экран практики

Local `/practice/`, 390×844: 7 крупных карточек, main высотой 2058 px; верхняя
поясняющая карточка и B1 занимают почти весь первый экран, остальные навыки
начинаются ниже. Layout не ломается. Без теста с пользователями это гипотеза
о затруднении выбора, а не доказанный отказ пользователя.
Предлагается компактный ряд навыков/якорей сверху и один контекстный следующий
шаг; полные карточки оставить ниже. Не дублировать профильные настройки.
Приёмка: на 390 px до прокрутки видны доступные направления; клавиатура/Back
работают; пользовательский тест «найди письмо/аудирование» сравнивает выбор
до/после. Усилие M, нужна проверка с пользователями.
[NN/g](https://www.nngroup.com/articles/ten-usability-heuristics/) — узнавание и
минимизация лишнего содержимого, не требование заданной высоты.

### PA-05 · P3 · PO / Designer · границы глобального поиска

Local `/search/?q=kawa` даёт 0 результатов, хотя слово есть в материалах.
[search](../backend/polskiflow/catalog_search.py) намеренно ищет публичные
metadata, а не содержимое уроков/личные слова: текущий контракт не нарушен.
Предлагается явно написать «Поиск по названиям и описаниям» с примером запроса,
а поиск слов внутри материалов проектировать отдельно по потребности beta.
Приёмка: пользователь понимает область поиска до отправки; пустое состояние
объясняет ограничение и ведёт к словарю/курсу без обещания существующего
полнотекстового поиска. Усилие S для copy; полнотекстовый поиск вне этого этапа.

## Известные зависимости — без новых дублирующих задач

  первее косметического расширения аудирования. Реестры не заполнены данным аудитом.
- **Реальный Safari/VoiceOver:** микрофон, stop/play, фон/lock/refresh/Back/сеть/timeout
  по существующему плану; эмуляция 390 px не закрывает этот пункт.
- **ИИ:** живой Groq и калибровка с преподавателем не проверены, флаги не включались.
- **P0:** legal/retention, удаление production test account, smoke Secrets/активация,
  независимые языковые рецензии и согласованная beta остаются открытыми.
