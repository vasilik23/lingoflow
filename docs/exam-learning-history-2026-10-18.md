# Экзаменационный путь и история письма · 18.10.2026

Срез RA-02/03/04 из внешнего аудита. Он не меняет объём учебного прогона
и не превращает самопроверку письма и речи в экзаменационный балл.

## Поведение

- Вход B1 явно называет учебный прогон пяти частей. Отдельное письмо доступно
  из выбора навыка: один из трёх комплектов, два текста, общий лимит 75 минут.
- Разбор объективных частей предлагает «Все», «Ошибки», «Пропуски» с числами.
  Без JavaScript остаются все ответы. Нумерация вопросов сохраняется.
- Reading возвращает к исходному тексту своего задания; listening открывает
  соответствующую расшифровку. Ссылки учитывают закреплённую версию прогона.
  У грамматики остаются существующие ссылки к теории.
- Отдельное письмо автоматически отправляет только агрегат завершённой
  попытки: UUID, комплект/версию, начало/конец, timeout, оставшиеся секунды,
  число слов каждого текста. Черновики остаются в браузере. Старые локальные
  попытки без UUID/начала не превращаются в выдуманную историю.
- При ошибке виден неподтверждённый статус и кнопка повтора. Повтор и refresh
  используют тот же снимок; потерянное подтверждение не создаёт дубль.
  Ожидающий запрос ограничен 15 секундами. Поздний ответ старой попытки
  не помечает новую сохранённой. Подтверждение из другой вкладки не сбрасывает
  самопроверку/ИИ; замена попытки по-прежнему сбрасывает их.
- История показывает последние 12 попыток за выбранный период, пропуски,
  число слов и время без автоматического балла. Данные явно обозначены
  как переданные браузером, не как проверенный экзаменом результат.
- Экспорт аккаунта 2.3 включает новый набор `b1_writing_attempts`; удаление
  владельца каскадно удаляет эти строки. Privacy и backup count checklist обновлены.

## Хранение и безопасность

Supabase-миграция `20261018084659_b1_writing_attempts.sql` применена перед
публикацией приложения. Django 0124 отражает managed=False модель.
Таблица разрешает authenticated только SELECT/INSERT под owner-RLS;
UPDATE/DELETE и доступ anon запрещены. FK `auth.users` ON DELETE CASCADE.
RPC `save_b1_writing_attempt` работает как SECURITY INVOKER с пустым search_path,
выводит владельца из auth.uid(), атомарно различает saved/duplicate/conflict.
Строка неизменяема. Нет столбцов текста или оценки. Тайминг и диапазоны
проверяются как в Django, так и ограничениями БД; RPC отклоняет лишние ключи.
CSRF-защищённый session endpoint отклоняет bearer, большие/невалидные payload
и использует существующий лимит мутаций. Токен HttpOnly не открывается JS.

В транзакции с rollback проверены создание, повтор, конфликт, лишний essay,
невидимость другому владельцу и запрет чужого INSERT. Проверки grants подтвердили
отсутствие доступа anon и UPDATE/DELETE. Новых замечаний security advisor нет;
ранее существовавшие предупреждения rate-limit definer/password protection
не переопределялись этим срезом.

## Проверки

Браузер письма: RU/PL/EN × 390/1440 px, 6 раскладок. Синтетическая недоступность
сохранения → refresh → повтор → подтверждение → refresh. Проверены неизменный
payload из 9 полей, отсутствие текста в запросе, сохранность черновиков,
отсутствие overflow и JS-ошибок. Подменённый ответ не считается живым сохранением.
Оно проверяется отдельно после публикации.

Независимая редактура, наблюдения учеников, живой Groq и физический Safari
этим срезом не закрываются. Production AI остаётся выключенным.

Разбор: RU/PL/EN × 390/1440 px — 18 раскладок трёх объективных частей,
54 выбора фильтров клавиатурой со сверкой числа/видимых ответов/aria-pressed,
36 переходов к исходным текстам и расшифровкам с раскрытием и фокусом summary.
Проверены grammar-ссылки на существующие уроки, неизменность подписанного
run_token, отсутствие overflow/JS errors. Без JS три разбора сохраняют
все ответы и нативные раскрываемые источники. Вход B1 проверен в 6 раскладках.

Локально: полный прогон 1108 Django tests — PASS; дополнительный новый
localization-модуль (3 теста, включая добавленную проверку состояний истории)
— PASS. System check, migration drift, msgfmt и diff check — PASS.
