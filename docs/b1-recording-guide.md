# Записи для учебного прогона B1

## Подготовлено

Подключение локальных MP3/OGG/WAV, видимая атрибуция, два прослушивания,
30-секундная пауза, восстановление счётчика и остановка при уходе/истечении
таймера реализованы. Реестр `b1_listening_recordings.RECORDINGS` пока пуст:
проверенные записи не опубликованы, текущие прогоны используют системный голос.

[Пакет для диктора](b1-recording-packet.json) содержит три оригинальных текста,
контрольные суммы и вопросы для проверки записей. Он воспроизводится командой:

```bash
cd backend
.venv/bin/python manage.py b1_recording_packet > ../docs/b1-recording-packet.json
```

## Выпуск записи

1. Записать точный польский текст соответствующего варианта. Не читать вопросы
   и не добавлять вступление. Сохранить все числа, даты и исправления информации.
2. Удалить длинную тишину; проверить отсутствие музыки, перегрузки и шума.
   Использовать естественный ясный темп. Файл должен содержать полный текст.
3. Подтвердить права на распространение голоса и самой записи. Для студийного
   заказа сохранить письменное разрешение и доступное доказательство прав.
   Права на исходный текст не заменяют разрешение исполнителя.
4. Передать файл польскоязычному редактору. Прослушать его полностью, сверить
   с текстом и проверить ответы на все пять вопросов прогонного аудирования
   (`training_questions(variant, 'listening')`); пакет включает все пять вопросов.
   Подтвердить произношение, естественность и пригодность темпа для B1.
5. Добавить неизменяемый файл с уникальным именем в
   `backend/polskiflow/learning/static/polskiflow/audio/b1/`. Не заменять байты
   ранее выпущенного файла и не переиспользовать ID записи.
6. Добавить `ListeningRecording` в реестр: ID, variant ID, static path,
   SHA-256 файла и точного UTF-8 текста, заголовок, исполнитель, лицензия,
   HTTPS-ссылки на лицензию и источник, изменения, редактор и дата проверки.
   Зафиксировать доказательство прав в реестре источников. Новую редакцию
   добавлять в конец реестра: новые прогоны выбирают её, а старые сохраняют
   прежний ID. Сохранять предыдущие записи и файлы.
7. Выполнить Django `check`, тесты и migration drift check. System check
   отклоняет отсутствующие файлы, несовпадающие контрольные суммы, неполные
   метаданные, неподдерживаемые лицензии и повторные ID/пути.
8. Проверить Preview в браузере: отсутствие автозапуска, атрибуцию, две попытки,
   паузу, перезагрузку, ошибки загрузки, остановку и мобильный экран. Затем
   выполнить обычный выпуск и production smoke.

Новое состояние прогона закрепляет ID выбранной записи. Старые прогоны
сохраняют системный голос; исчезнувшая закреплённая запись не подменяется
другим источником. Непроверенный файл нельзя добавлять в реестр. Добавление
технически корректных метаданных само по себе не подтверждает права или B1-уровень.
