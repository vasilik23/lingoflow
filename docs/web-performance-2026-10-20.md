# Заголовок урока и скорость web · 20 октября

## Воспроизведение

На польском мобильном экране «Narzędzia lekcji» и подзаголовок склеивались.
После перевода блока из `details` в обычный `section` CSS продолжал оформлять
только `summary`. Оформление постоянного заголовка исправлено: две строки,
отступы, меньший второстепенный текст, без возвращения сворачивания.

Контрольный проход обычным QA-аккаунтом до изменения, Chromium, PL,
одна успешная авторизованная загрузка на маршрут:

| Страница | Окончательные заголовки | DOMContentLoaded |
| --- | ---: | ---: |
| Сегодня | 2449 ms | 2631 ms |
| Урок грамматики | 2636 ms | 2784 ms |
| Курс | 3029 ms | 3198 ms |

Использован `finalResponseHeadersStart`: `responseStart` здесь отражал ранние
HTTP Early Hints и давал ложные 30–40 ms. Более ранний проход с переходом
на login не является измерением скорости авторизованных страниц. Это
контрольные наблюдения, не p95, нагрузочный тест или данные реальных iPhone.

## Что ускорено

- Подтверждено несоответствие регионов: runtime `iad1` в `X-Vercel-ID`,
  Supabase project metadata — `eu-west-1`. В `backend/vercel.json` задан
  единственный регион `dub1`, рядом с базой. База и данные не перемещаются.
  [Рекомендация Vercel](https://vercel.com/docs/functions/configuring-functions/region)
  и [соответствие регионов](https://vercel.com/docs/regions).
- Независимые HTTP-чтения на Сегодня, курсе и странице урока выполняются
  параллельно в ограниченном пуле на время одного запроса. В эти workers
  не передаются ORM-операции или записи. Наборы token/owner прежние,
  RLS, таймауты и состояния недоступности сохранены.
- Сегодня читает каталог уроков один раз вместо двух/трёх SQL-запросов.
- Добавлен `Server-Timing: app;dur=…`: только длительность, без ID, токенов
  и пользовательских значений. Существующие метрики заголовка сохраняются.

Общего кэша персональных страниц/данных и кэша авторизации нет. Параллельные
чтения не уменьшают число обращений к Supabase и не заменяют проверку
бюджета latency по реальным наблюдениям закрытой beta.

## Проверки

- 1124 Django tests, system check, migration drift — PASS.
- Barrier-regression доказывает перекрытие чтений; проверены порядок
  результатов, owner/token, состояния недоступности и один каталог на Today.
- Локальный браузер: 36 сочетаний RU/PL/EN × обе темы × 320/390/1440 px
  × обычный/125% шрифт. Нет склейки заголовков, горизонтального переполнения
  и ошибок JS. Нативный Safari/iPhone этим прогоном не подтверждён.
- При выпуске нужно подтвердить фактический `dub1` в заголовке ответа и
  повторить авторизованный контрольный проход. Один контрольный проход
  не закрывает критерии общей beta или пользовательскую приёмку.

Откат: предыдущий deployment/commit возвращает регион и последовательные
чтения вместе. Миграций и изменений прав доступа нет.
