# Проверка письма с ИИ — пилот Groq

Реализовано в `/writing/` (B1/B2) и в двух редакторах письма пятичастного
прогона B1. Это отдельный разбор текста; результат не меняет прогресс,
экзаменационный итог или самопроверку. Речь пока не подключена.

## Что получает пользователь

Четыре критерия по 0–5: выполнение задания, структура/стиль, грамматика,
словарь. Учебный итог — 0–20, без соответствия официальной шкале B1.
До шести ошибок: точная цитата, исправление на польском и объяснение на
RU/PL/EN; одна конкретная рекомендация. Отсутствие ошибок в ответе модели
не означает безошибочный текст. Изменение текста сбрасывает прежний разбор.

Текст и задание уходят в Groq только после отметки согласия и нажатия
«Проверить с ИИ». Завершение части, таймер и обычная самопроверка не запускают
ИИ. При недоступности сервиса или квоты редактор остаётся доступен.

## Подключение владельцем

1. Создать аккаунт и API-ключ в [Groq Console](https://console.groq.com/keys).
   Для бесплатного пилота использовать Free plan; подключение LingoFlow
   не включает оплату и не меняет тариф. Квоты общего ключа могут закончиться
   раньше локального лимита на пользователя.
2. В Groq Data Controls включить Zero Data Retention. Проверить условия
   обработки и международной передачи данных до открытия публичного пилота:
   [Groq Your Data](https://console.groq.com/docs/your-data).
3. В Vercel → проект `lingoflow-learn` → Settings → Environment Variables
   добавить `GROQ_API_KEY` как секрет для Production и
   `GROQ_WRITING_ENABLED=true`. Модель по умолчанию —
   `openai/gpt-oss-120b`; менять её только после проверки поддержки strict
   JSON Schema и параметра reasoning_effort. Не отправлять ключ в чат или Git.
4. Выполнить Redeploy production, чтобы применить переменные. Для локальной
   работы передать те же переменные процессу Django через Run Configuration;
   `manage.py` не загружает `.env` автоматически.
5. Проверить на своём аккаунте `/writing/`: отсутствие отправки без согласия,
   письмо на польском, все четыре критерия и конкретные исправления. Проверить
   короткий и длинный текст B1. Сверить модель с преподавателем на наборе
   ответов с известными ошибками; до этого не считать качество откалиброванным.

До настройки ключа и флага экран честно показывает «ИИ пока не подключён».
Живой вызов Groq не подтверждён: локальные тесты используют фикстуру провайдера.

## Ограничения и данные

- Только авторизованный браузер, POST с CSRF, явное согласие; задание подписано
  сервером, привязано к владельцу и действует 4 часа.
- Не больше 6000 символов и 10 запросов за окно 24 часа на аккаунт. Счётчик
  в закрытой Supabase-таблице `private.api_mutation_buckets`, RPC проверяет
  `auth.uid()`. При недоступном счётчике запрос к модели не выполняется.
  Сбои провайдера тоже расходуют попытку; платного fallback и повторов нет.
- Groq получает текст и задание, без ID аккаунта и e-mail. Текст и ответ модели
  не сохраняются в базе LingoFlow, истории или технических журналах. Разбор
  существует только на странице; локальные черновики сохраняют прежние правила.
  Политика Groq независима от хранения в приложении.
- Ответ модели проверяется сервером: типы, границы баллов, длины полей,
  точные цитаты. Refusal, обрезанный/неправильный ответ не превращается в балл.
  Вывод в браузере через textContent, без исполнения HTML модели.
- Миграция `20261008091310_ai_writing_rate_limit.sql` применена перед выпуском;
  RLS/grants сохранены. Проверены лимит и изоляция владельцев транзакцией
  с rollback. Advisors до/после: одинаковые существующие предупреждения
  об RPC SECURITY DEFINER и leaked-password protection; новых нет.

## Дальше

После живой проверки письма добавить запись → польскую расшифровку Whisper →
подтверждение расшифровки → языковой разбор. Произношение требует отдельной
работы с аудио и проверки качества; не оценивать его по одному транскрипту.
